# StarCatch

StarCatch는 Windows용 퍼즐 게임입니다. 이 저장소는 실행 파일 배포 전용이며 소스 코드는 포함하지 않습니다.

## 다운로드

[Releases](https://github.com/chmir/StarCatch-Releases/releases/latest)에서 최신 버전의 `StarCatch_v{버전}_win-x64.zip`을 받습니다.

## 실행

1. zip 파일의 압축을 풉니다.
2. `StarCatch.exe`를 실행합니다.

- Windows 10 이상, 64비트에서 실행됩니다.
- .NET 런타임이 포함된 단일 파일이라 별도 설치가 필요 없습니다.
- 처음 실행할 때 Windows SmartScreen 경고가 뜨면 "추가 정보"에서 "실행"을 누릅니다.

## 버전 표기

버전 끝의 `a`는 알파 빌드를 뜻합니다. 각 릴리즈 노트에서 주요 변경 사항을 확인할 수 있습니다.
